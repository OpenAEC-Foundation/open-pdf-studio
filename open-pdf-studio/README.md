# open-pdf-studio (app folder)

This folder holds the Open PDF Studio app: the front end (`js/`, `styles/`,
`index.html`), the Tauri shell (`src-tauri/`) and the build and test scripts
(`scripts/`).

- What the app is and how to install it: the [README](../README.md) at the root
  of the repository.
- Building, running and testing it: [docs/building.md](../docs/building.md).
